# Arabic AI Study Assistant

مساعد دراسي عربي بسيط يساعد الطلاب على تنظيم أسئلتهم وتحويل الدروس إلى أسئلة للمراجعة.

## فكرة المشروع

يهدف المشروع إلى تقديم أدوات بسيطة باللغة العربية تساعد على:

- تلخيص موضوع دراسي.
- إنشاء أسئلة مراجعة.
- تبسيط شرح المفاهيم الصعبة.
- تنظيم خطة الدراسة.

## حالة المشروع

المشروع في مرحلة التطوير الأولى، وأرحب بالاقتراحات والمساهمات.

## الخطة المستقبلية

- إضافة واجهة عربية سهلة.
- إضافة دعم لملفات PDF.
- إضافة اختيار مستوى الصعوبة.
- ربط المشروع بنموذج ذكاء اصطناعي عبر API.
- إضافة اختبارات قصيرة للطلاب.

## المساهمة

يمكنك فتح Issue لاقتراح فكرة أو الإبلاغ عن مشكلة، أو إرسال Pull Request لتحسين المشروع.
